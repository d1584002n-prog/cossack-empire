# Козацька імперія (Fabric, Minecraft 1.21.4)

Мод-стратегія: карта провінцій, ресурси, полки, туман війни.
Збірка: GitHub Actions -> Artifacts -> cossack-empire.
У грі: клавіша M відкриває стратегічну карту (поки заготовка).

## Карта (тайлова)

Карта — 128×128 тайлів по 16 px (2048×2048 px). Провінції — області тайлів (≈4×4, сітка 32×32 = 1024 провінції);
гра працює з провінціями, а малюється тайлами. Атлас тайлів: `src/main/resources/assets/cossack_empire/tile_atlas.png`
(складений зі спрайтів **MiniWorld Sprites by Shade**, merchant-shade.itch.io — перевір ліцензію пакета перед публікацією).

Керування: колесо / `+` `-` — масштаб, перетягування — рух, `0` — вся карта, `#` — межі провінцій.

## Економіка, міста, технології

- **Міста** (вкладка «Міста»): 8 будівель на провінцію — ферма, ринок, шахта, стіни, казарми, бібліотека, порт, кузня.
  Рівень поселення залежить від кількості будівель: село → містечко → велике місто; перша провінція — столиця.
- **Економіка** (вкладка «Економіка»): населення (їсть їжу, росте, обмежене місцями в містах), податки (4 рівні; високі дають
  невдоволення), наука та торгівля ресурсами (ринки покращують ціни).
- **Технології** (вкладка «Технології»): 4 гілки по 3 рівні (економіка, військова справа, будівництво, управління).
  Кожна коштує золото і науку; рівень 2 і 3 потребують відповідної епохи.
- **Епохи**: Раннє середньовіччя → Королівська доба → Порохова доба. Нова епоха відкриває будівлі й технології.
- **Події**: набіги, неврожай, торговий бум, родовища, епідемії, повстання. Війну оголошують лише сусідні держави.
